## 📝 Descrição do Prompt de Pesquisa

Pesquisa aprofundada sobre as especificações do documento de identidade brasileiro **CIN (Carteira de Identidade Nacional)** com base no Decreto nº 10.977/2022:
- Unificação pelo número de inscrição no Cadastro de Pessoas Físicas (CPF) como registro geral único.
- Abolição de números de RG estaduais emitidos pelas secretarias de segurança pública.
- Campos presentes na face frontal e verso: Nome Completo, Nome Social (se houver), Data de Nascimento, Nacionalidade/Naturalidade, Data de Emissão, Data de Validade, Órgão Expedidor e Código de Verificação.
- Remoção de campos legados (como "Sexo" e obrigatoriedade de filiação visível na face principal).
- Padrões visuais para extração estruturada de dados via OCR.
