## 📝 Prompt na Íntegra (Raw)

```text
busque por biblioteca, sdks ou soluçoes open source
que possa ser integrar a uma API  para fazer extração de dados de pdf(muitos os caso o pdf vai conter uma imagem onde deve extrair esse dados) e imagens (o foco gerar extração de dados de documento de identidade Brasileira )
busca na comunidade ferramentas ja utilizada e ordene de acordo com facilidade integra e precisão
(1) Buscar bibliotecas de OCR e SDKs de código aberto capazes de processar PDFs e imagens para extração de texto.
(2) Pesquisar soluções, modelos ou projetos comunitários focados especificamente na extração de dados de documentos de identidade brasileiros, como RG e CNH.
(3) Investigar discussões em fóruns e comunidades de desenvolvedores para avaliar o uso prático, as recomendações e a viabilidade dessas ferramentas no Brasil.
(4) Para cada ferramenta ou biblioteca encontrada, analisar:
(a) facilidade de integração em uma arquitetura de API
(b) precisão no reconhecimento de caracteres em português e formatos de documentos
(c) capacidade de lidar com PDFs que contêm imagens embutidas
(d) suporte e documentação disponíveis
(5) Sintetizar as informações coletadas e ordenar as soluções identificadas com base no equilíbrio entre a facilidade de integração e a precisão na extração dos dados.
```
